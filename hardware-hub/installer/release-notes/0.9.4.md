Faster automatic printing:

- Check for waiting jobs every 1 second while idle.
- Claim the next job immediately after the current job finishes, with serial execution and existing recovery/ACK protection.
- Upgrade existing installations to 1-second polling while preserving printer selection, encrypted pairing credentials and journal data.
- Record PDF download, preparation and dispatch durations for support diagnostics.
- Decrypt the protected lease token once per active execution instead of launching Windows DPAPI/PowerShell for every event. Release the in-memory token reference when execution ends; journal storage remains encrypted.

Run Setup.exe using the same Windows account as the existing installation and choose the upgrade flow. Verify `ASIHJAYA-Hardware-Hub-Setup.sha256.txt` before distribution.

The companion RMS application update replaces PDF network-idle waiting with explicit photo, QR and font readiness. Deploy the RMS update to receive that part of the improvement. Network availability and printer/spooler speed still affect physical printing time.
